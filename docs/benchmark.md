# 竞品对比与压测报告

> 本机：Windows 12 核 / Go 1.26，`-benchtime=500000x`。
> 数据为单次测量参考，非跨平台承诺。

## 1. 结论

- **生成吞吐与 bwmarrin/snowflake 持平**（~244ns/op，0 分配）；
- **sony/sonyflake 慢约 160 倍**（~39µs/op）；
- idgenx 的差异化价值在功能（可配置位布局、回拨策略、解析、
  短 ID、errx 打通），性能不构成短板。

## 2. 压测数据

| 库 | 耗时/op | 分配 |
| --- | --- | --- |
| idgenx | 243ns | 0 allocs |
| bwmarrin/snowflake v0.3.0 | 244ns | 0 allocs |
| sony/sonyflake v1.3.0 | 39078ns | 0 allocs |

## 3. 功能矩阵

| 能力 | idgenx | bwmarrin/snowflake | sony/sonyflake |
| --- | --- | --- | --- |
| 位布局可配置 | ✅ | ❌ 固定 | ❌ 固定 |
| 纪元可配置 | ✅ | ✅ | ✅ |
| 时钟回拨策略 | ✅ 等待/拒绝/宽松 | ❌ | ⚠️ 简单处理 |
| ID 解析（时间/节点/序列） | ✅ | ⚠️ 部分 | ⚠️ 部分 |
| 序列随机起点 | ✅ | ❌ | ✅ |
| 短 ID | ✅ 同库 | ❌ | ❌ |
| 结构化错误（errx） | ✅ | ❌ | ❌ |
| 日志/指标注入 | ✅ | ❌ | ❌ |
| 外部依赖 | 0（仅 errx） | 0 | 0 |

## 4. 总结

- 性能与最主流雪花库持平，0 分配；
- 功能覆盖（回拨策略/可配置布局/解析/短 ID）是自研的核心收益；
- 后续迭代重点保持正确性与 API 稳定性，无需为性能做激进优化。
